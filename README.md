# alpha_fake_python_terminal

A fake Python terminal CLI application.

## Usage

To run the application:

```bash
dart run
```

Or install it globally:

```bash
dart pub global activate alpha_fake_python_terminal
alpha_fake_python_terminal
```

## Features

- Mimics the Python REPL interface.
- Accepts input but does nothing (fake execution).
- Supports `exit()` and `quit()` commands.
